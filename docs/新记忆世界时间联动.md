# 新记忆与世界时间

聊天设置的自定义时间下方，以及变量记忆的设置页面，都可以找到“新记忆跟随世界时间”。默认开启，设置自动保存。

- 开启自定义时间：新消息保存当时的世界时间。
- 暂停世界时间：暂停期间的新消息使用固定世界日期。
- 关闭自定义时间或关闭联动：新消息使用现实时间。
- 后来修改日期、关闭联动、跨天或延迟提取，已保存的消息时间快照不变。
- 已有消息和记忆不回填、不迁移。提取旧聊天仍使用旧的时间依据。

展开“时间规则”，可以设置本聊天或全局默认、原文日期优先级、相对日期参照、无明确日期的当场事件、时间衰减与半衰期。

默认尊重原文明示日期；“昨天／明天”以来源消息当时的世界日期推算；模糊往事保持时间不明。计划保存提出日期与执行日期，没有时分依据时只显示执行日期。

独立世界时钟可设置日期、IANA 时区（例如 `Asia/Shanghai`、`UTC`）、流逝倍率及暂停状态。现有全局世界时钟也可以设置倍率；倍率 1 为正常流逝，0 为固定时间。暂停按钮还会配合已有的离开间隔与后台暂停设置。

聊天设置 → 时间感知 → “角色所在地 / 时区”可选择角色所在城市，默认跟随“我的时区”。AI 会分别收到用户和角色的当地日期、时间与时段，问候不再代表双方处于同一时段。群聊沿用各成员的角色时区，也可在群成员设置中修改；关联角色会同步设置。自定义时间及独立世界时钟均以同一个世界时刻换算双方时间，保留暂停、倍率、跨日和夏令时处理；不会修改已保存的消息时间快照。

新建或切换时间线不删除任何记忆。可以分别决定是否调用其他时间线的事件、共享其他时间线的核心／用户／角色设定和禁忌规则。旧记忆继续按原逻辑使用。

新记忆日期旁的时间来源按钮可以打开详情：检查来源原文、恢复自动日期、选择世界／现实／原文日期、标记未知或手动指定日期和范围。原来的直接修改日期框仍然可用。手动日期不会被后续自动内容更新覆盖。

批量菜单提供平移日期和撤销上次日期调整。日期不明的条目跳过；写入失败会恢复原数据。完整记忆导出保留时间规则和时间元数据，聊天备份保留消息快照。

现实消息时间戳继续用于原来的排序和提取进度，世界时间独立用于事件日期；没有改变原消息时间戳或旧记忆的衰减逻辑。
