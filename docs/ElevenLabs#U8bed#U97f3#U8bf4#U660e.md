# ElevenLabs 语音

在 API 设置的“服务”分类中填写 ElevenLabs Key，选择模型并保存。角色设置中开启 TTS、选择 ElevenLabs，再填写音色 ID 或获取音色列表。MiniMax 的原配置保留，每个角色可以独立选择服务。

“检查连接”只检查模型接口和鉴权，不生成声音。“生成试听”会产生 API 用量，能进一步验证模型、音色和账户权限。音色示例与自定义试听是不同操作。

聊天语音、语音/视频通话和 MP3 下载使用角色当前配置。API 设置允许为通话单独指定模型，角色指定模型时优先使用角色模型。声音参数留空时沿用服务端音色设置；两家音色和语速分别保存。

默认临时缓存生成音频。开启“保存生成音频”后，音频保存到该条聊天消息，随角色及完整备份导出，增加本地存储。已保存音频保持原声；长按语音条可重新生成。角色设置的清理入口只清理保存的合成音频，保留文字和真实录音。

双语朗读跟随现有语言设置。长文本超限不会截断；开启分段后顺序朗读，多段下载为 ZIP 音频包。可选聊天流式播放在浏览器支持时增量播放，不支持时使用同一次请求取得的完整音频。取消播放不会取消仍在下载的相同音频，但已提交请求可能产生服务端用量。

ElevenLabs 模型能力不同。Multilingual v2 不发送强制语言参数；选择自动识别时不强制普通话。粤语需要支持相应方言的模型、合适音色和实际试听，应用不会将粤语选项直接当作普通话参数发送。

自定义接口地址需要兼容 ElevenLabs 协议，不是 OpenAI TTS 接口。Key 由用户自行提供；角色卡和声音参数预设不携带 Key，完整 API 备份仍遵循原项目的凭据备份行为。

本次接入保留现有单聊 TTS 与通话范围；群聊多音色、应用内声音克隆及 ElevenLabs 转写是独立功能，未改变现有录音理解和群聊行为。
